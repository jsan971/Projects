## Application Name : doit

The purpose of this application is to track user tasks through a terminal
(command line interface). The application is designed for a single user to organize and track
tasks

### Features required to be considered complete: 
    - CRUD (Create, Read, Update, Delete)
    - Storage solution 
        - This allows the user to track previous tasks 
            Persistent storage via local txt file to add/modify changes automatically this prevents
            data loss such the application is terminated abruptly
    - Task Status (Pending, Open, Complete) - Allow the user to add or modify a task’s
    status.
    - Clear all tasks - Provide the ability to wipe all tasks within the application and resetting
    the tasks.txt
    - Color Coded Console Output. Given this is a terminal based application, readability is
        important. Status will have specific colors assigned when viewing/displaying the list of
        tasks that include a status.
        - Pending = Blue
        - Open = Green
        - Complete = Red

## Stretch Features / Optional : 
    - Due Dates - Allow the user to add specific due dates for new and existing tasks
    - Filtering - Allow the user to filter based on the tasks that have a set status which are
      pending, completed or in progress.
